# Portable Laravel contributor contract

This folder is independently copyable. Keep its two public entrypoints, configuration/defaults, stdlib Python package, templates, documentation and tests here. Never import parent libraries, load a parent `.env`, invoke parent automation scripts, depend on setup.sh, or duplicate production logic in a root integration. Run Bash from Fish/Zsh; never source `.env`. Require Python 3.9+ and Bash 4.4+.

Preserve production credentials, existing websites/databases, uploaded files and manual edits. Read-only commands must not install, initialize config, download external scripts in dry-run, change services or write state. Installation requires explicit authorization, exact native package availability and operation-specific prerequisites. Repository additions, external code, service changes, firewall/SSH/TLS and migrations have separate review controls. No root deployments, automatic host trust acceptance, embedded credentials, insecure permissions or unverified remote shell execution.

Use release directories, persistent shared data, locks, pre-activation checks, atomic activation, loopback health checks, recovery receipts and rollback without automatic schema reversal. Templates are bounded bundled data. Remove obsolete replacements rather than relocating duplicate installers. Keep tests and docs synchronized. Before edits and delivery run `python3 scripts/validate.py` from this folder; inspect every skip. Native integration uses only `python3 scripts/podman_test.py --allow-install ...` in disposable rootless Ubuntu, never host provisioning. Only this folder may enter that fixture; exclude `.env`, keys, caches and generated data. Verify teardown. Report command fixtures, native daemons, real systemd/VM and public TLS tests separately. Do not install lint tools on the host just for testing. No branches, commits, staging, tags or generated release archives without owner instructions.
