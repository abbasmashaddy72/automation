# Upstream reference review

The historical [Forge provisioning example](https://gist.githubusercontent.com/jacurtis/110da6be70e9922f9fbaf8b89def6ae9/raw/b5917a5b4002d0debaab5c3f9d6c52a2a89ed342/forge.sh) was downloaded and inspected locally before implementing provisioning. Its downloaded SHA-256 was `d0662844da7c377b0b1033f9ce1fb0994d9183a570cc8554eb101491663f7f38`. It was never executed. Responsibilities such as web/FPM services, deployment account, queue/scheduler and log rotation were useful; obsolete PHP/Python versions, insecure repository/key bootstraps, embedded credentials, hardcoded callbacks and broad permission changes were excluded.

[Laravel deployment preview](https://github.com/bakerkretzmar/laravel-deploy-preview) informed separation of deployment concerns. The [Forge action](https://github.com/marketplace/actions/deploy-to-laravel-forge) requires a Forge account/token and server/site identities, which are deliberately absent here. Direct SSH invocation works with any suitable CI system.

The [Laravel deployment shell reference](https://github.com/hbollon/Deploy-script-Laravel/blob/master/deploy_script.sh) was also retrieved and inspected locally (SHA-256 `51f4e52a1e72583d7e290d2fce4aa5533f87b2211fce9af8becd94f2ce23da82`). Its live-checkout hard reset, unconditional downtime/migrations, storage-link deletion, unlocked npm installation and assumed `prod` script were replaced with isolated releases, explicit migration review, shared persistent storage, lockfile installs and actual script discovery. Reference scripts were not copied into the runtime.

Current primary guidance: [Laravel deployment](https://laravel.com/framework/docs/deployment), [Laravel isolated migrations](https://laravel.com/framework/docs/11.x/migrations), [queues](https://laravel.com/framework/docs/queues), and [Ubuntu archive verification](https://documentation.ubuntu.com/security/software-integrity/archive-verification/). Availability is checked from configured APT repositories at execution; documentation does not imply a requested PHP version is present.
